# NOTE Sandbox v1.0: CI's first run

What the first CI run of Blocks 1 to 4 found (run 39331473048), and what follows.

- **A unit test failed on every version:** `testWhileOnTheSandboxMustStart` asserted
  bwrap missing after an earlier call in the same test had cached `/usr/bin/bwrap`.
  On the runner, where bubblewrap is installed, the cached path stays valid;
  in the harness, where it is not, it was dropped, so the test passed there.
  The test now forgets the cache first. The code was right.
- **The three sandbox tests skipped on the runner,** bubblewrap 0.9.0 installed:
  the probe found that it cannot start a sandbox there.
  CI's PHPUnit now prints the reasons of skipped tests (`--display-skipped`),
  so the next run says why; Ubuntu 24.04's AppArmor restriction on unprivileged
  user namespaces is the likely one. What to do about it, in CI and for
  administrators, is decided once the reason is known.
